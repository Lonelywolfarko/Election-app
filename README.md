# Election-Guide-Assistant
Interactive Election Guide Assistant using Flask and Vanilla JS

A personal project that helps users understand the election process, eligibility, registration steps, and voting journey through an interactive web assistant.

---

## 🚀 Features

- Eligibility Checker
- Step-by-step voting journey
- Chat assistant for queries
- Location-based election info
- Document checklist generator

---

## 🛠️ Tech Stack

- Frontend: HTML, CSS, Vanilla JavaScript
- Backend: Python (Flask)

---
⚠️ Disclaimer

This is a beta / educational project. All data is mock and not official election information.
